# 漢字テスト（小学1〜4年）

- よみテスト: 文の中の漢字を読む（声・キーボード・自分で丸つけ）
- かきとりテスト: ひらがなの部分を指やペンで漢字に書く（形・画数・書き順を自動判定）／10問の用紙を印刷して紙に書き、写真をGemini APIで採点（APIキーは各端末のブラウザに保存）

公開ページ: https://ytanoue-arch.github.io/kanji-test/

記録は各端末のブラウザ（localStorage）に保存されます。
